# Trikonekt UI assets

Repo-ready starter asset pack for the premium emerald/teal Tri Shopping theme.

## Folders
- `backgrounds/`: scalable SVG backgrounds for app, header, and cards.
- `banners/`: location, subscription, Explore Near Me, and deal banner backgrounds.
- `icons/category/`: category icon SVGs.
- `icons/navigation/`: Home, Tri Zone, Scanner, Online, Near Store.
- `icons/ui/`: wallet, notification, search, location, arrow, crown.
- `illustrations/`: nearby map and empty states.
- `css/theme-tokens.css`: starter CSS variables and utility classes.

## Usage
Copy the `trikonekt-ui-assets` contents into your app's existing `public/assets/` directory, or copy selected folders into your established asset location. SVGs can be referenced from public paths, for example `/assets/backgrounds/app-background.svg`.

For React, use `<img src="/assets/icons/category/gift.svg" alt="" />` or the project's existing icon component. Use CSS `background-image` only for decorative backgrounds. Keep interactive controls and text as real components.

The assets are editable vector SVGs. Review sizing, accessibility, brand logo usage, and contrast in the app before release. Promotional product photography should use approved product assets, not these abstract banner backgrounds.
