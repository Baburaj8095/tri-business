# Trikonekt Business UI Asset Pack

Includes the generated reference board, banner crops, brand/splash reference crops, category and product image crops, merchant illustration sheet, UI reference sheets, standalone SVG starter icons, and reusable CSS design tokens.

IMPORTANT: The PNG/JPG reference crops are extracted from a generated composite design board. They are useful as visual guides and temporary placeholders, but they are not clean original source photography, transparent cutouts, or individually authored production illustrations. Some crops may include background or neighboring pixels. Replace with clean, licensed source assets before production. The logo crop is a reference only; use approved brand artwork if available.

Keep all live product, price, inventory, order, wallet, discount and payment data connected to the existing backend. Do not use screenshot crops as entire interactive screens.
